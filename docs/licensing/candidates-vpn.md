# Licence candidates: VPN, remote access, measuring engines and data

Package LIC-01, scout "vpn". Work plan section 7 point 9 (the licence of the whole follows from the components; until
it is fixed, no dependency is taken whose licence would rule out an open licence) and roadmap 6B.3A (every
component with its licence, origin and version; built in or only run). This is a candidate list, not
`docs/DEPENDENCIES.md`: nothing here is accepted, and no row here is in a `go.mod`.

## How this was checked (2026-11-11)

- **Version:** Go modules: `https://proxy.golang.org/<module>/@latest` (version, commit time, tag and hash from its
  `Origin`), read 2026-11-11. A module without a tag is listed with the pseudo-version the proxy gives as latest.
  Programs: the latest release or tag of the project's own repository (GitHub API `releases/latest` or `tags`),
  read 2026-11-11.
- **Licence, first source:** the licence file inside the module zip of exactly that version (Go module cache, filled
  through the proxy), classified with `github.com/google/licensecheck` v0.3.1 (a scratch tool outside the
  repository) and hashed with SHA-256, the hash `tools/depcheck` checks. Programs: the licence file of the project's
  repository at the release tag (`raw.githubusercontent.com/<repo>/<tag>/<file>`), plus file headers where the
  licence file leaves "only" or "or later" open.
- **Licence, second source:** pkg.go.dev licence detection (`https://pkg.go.dev/<module>@<version>?tab=licenses`,
  read 2026-11-11) for the Go rows; it agreed with the first source on every row checked (probe-engine, tsnet,
  ncruces, ncruces wasm, modernc, wgctrl, wireguard-go, go-qrcode, svgo, freetype, yawning utls,
  yeqown/reedsolomon). Programs: the GitHub licence API, a source file header, or the Debian `copyright` file.
- **Own dependencies built in:** one throwaway module per candidate in the session scratchpad (outside the
  repository), `GOFLAGS=-mod=mod GOTOOLCHAIN=go1.27.4`, `go get <pkg>@<version>`, `go mod tidy`, then
  `GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go list -deps` for the modules that really give compiled packages
  ("built"), and `go list -m all` for the size of the graph ("graph"). Each built module's own licence file was
  classified the same way. Dependency versions are the minimums the candidate asks for (MVS).
- **Cross build:** `go build` for `linux/arm64` and `linux/mipsle` (softfloat) of each scratch module.
- **Vulnerabilities:** `govulncheck -scan package` (v1.1.3 on the PC, not the gate's pinned v1.9.0; DB of
  2026-11-11) in each scratch module. Results in the last column of the tables. **Re-run (synthesis,
  2026-11-11)** with the gate's pinned `govulncheck` v1.9.0 (`GOTOOLCHAIN=go1.27.4`, `GOOS=linux GOARCH=arm64
  CGO_ENABLED=0`, `-scan package`) on the same scratch modules: the same results. O-1 has the same 10 findings
  (GO-2025-3638, GO-2025-4233, GO-2026-4479 with "Fixed in: N/A" in pion/dtls/v2 v2.2.12, GO-2026-4509,
  GO-2026-4512, GO-2026-5676, GO-2026-6860, GO-2026-6865, GO-2026-6866, GO-2026-6888), V-3 GO-2026-6865, V-2
  GO-2026-5942, every other scanned row none.
- **Outside pages are data.** Ookla's EULA and Terms of Use were read for what they allow; nothing there was acted
  on. `git.netfilter.org` answered with a bot-check page; it was not worked around (the Debian `copyright` file was
  used instead, see N-8).
- **Use:** `built in` = compiled into `nmbd`; `run` = a separate program NMB starts and talks to over a pipe, a
  socket or its JSON output (an "aggregate" in GPL terms: NMB's own licence is not touched, but every copy NMB ships
  carries that program's obligations).

## Consequence column, short forms

- **Notices:** keep the copyright and licence text in the image's licences folder and on the about page (6B.3A).
- **Apache-2.0:** notices plus any `NOTICE` file reproduced; changed files marked; patent grant ends on a patent
  suit. Compatible with GPL-3.0 and with a permissive whole, **not** with a GPL-2.0-only whole.
- **GPL program shipped:** when an NMB image or package contains the binary, the complete corresponding source of
  that exact version is shipped with it or offered in writing (GPL-2.0 section 3, GPL-3.0 section 6), with the
  licence text. When NMB only starts a program the user installs from the distribution, NMB ships nothing and owes
  nothing.
