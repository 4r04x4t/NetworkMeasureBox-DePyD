# Licence candidates: build, gate and image tools, base parts, kernel and firmware

Package LIC-01, scout "build". Work plan section 7 point 9 (the licence of the whole follows from the components;
until it is fixed, no dependency is taken whose licence would rule out an open licence) and roadmap 6B.3A (every
component with its licence, origin and version; built in or only run). This is a candidate list, not
`docs/DEPENDENCIES.md`: nothing here is accepted by it, and no row here adds anything to a `go.mod`. It is not legal
advice; where the sources disagree, the row says so and names the reading taken.

## How this was checked (2026-11-11)

- **Go parts.** Latest version: `https://proxy.golang.org/<module>/@latest` (tag, commit time, `Origin` ref), read
  2026-11-11; Go itself from `https://go.dev/dl/?mode=json` (current releases `go1.27.4`, `go1.26.11`) and the date
  from `https://go.dev/doc/devel/release` ("go1.27.4 (released 2026-11-10)"). Licence, first source: the licence file
  in the module zip of that exact version in the Go module cache, classified by its text and hashed with SHA-256
  (the hash `tools/depcheck` checks). Second source: `https://pkg.go.dev/<module>@<version>?tab=licenses`.
  Dependencies of each gate tool: one throwaway module per tool in the session scratchpad (outside every
  repository), `GOFLAGS=-mod=mod GOTOOLCHAIN=go1.27.4`, `go get <tool>@<version>`, then `go list -m all` (graph) and
  `go list -deps <cmd package>` (the modules that really provide compiled packages, "built").
- **Upstream C projects and tools.** Latest release: the project's own release list (GitHub `releases/latest` API,
  GitLab tags API for QEMU, `https://download.qemu.org/`, `https://www.kernel.org/releases.json`,
  `https://downloads.openwrt.org/releases/`, Alpine `latest-releases.yaml`, the Debian mirror `Release` file,
  `https://busybox.net/` news, `https://sources.debian.org/api/src/<pkg>/`). Licence: the project's licence file or
  source header at the tagged version (or commit) named in the row; GitHub's licence detection
  (`/repos/<r>/license?ref=<tag>`) as a second source where it gives an id.
- **What NMB's own material has.** The installed-package databases of the image analyses (`L:` fields of
  `lib/apk/db/installed` in the unpacked roots under `~/nmb-work/I-0{1..5}/`, `APKINDEX` of the Alpine repositories
  in `~/nmb-work/I-07/r2/repo/`), the image records `docs/images/*.md` of the native repository (I-01..I-07), the
  OpenWrt package `Makefile`s at tag `v25.12.6` (`https://raw.githubusercontent.com/openwrt/openwrt/v25.12.6/...`),
  and the Debian copyright files of the development PC (`/usr/share/doc/<pkg>/copyright`, Ubuntu 24.04) for tools
  that run there.
- **Not worked around.** `git.netfilter.org` and the dnsmasq gitweb answered with a bot check page (netfilter) and
  a "prove you are human" page (dnsmasq) to automated requests; these were not bypassed. For nftables, libnftnl and
  dnsmasq the licence comes from the distributions' metadata and copyright files instead (named in the row).
- **Outside content is data.** Nothing fetched was run; every download went to its own empty folder in the
  scratchpad. No personal data, box data or project findings went into any request. No author names are copied
  from licence texts.

Abbreviations, **NMB would**: **BUILD IN** = compiled into `nmbd`; **BUILD ONLY** = runs on the development PC to
build or check, nothing of it reaches `nmbd` or the image; **TEST ONLY** = runs on the development PC for tests;
**SHIP (RUN)** = a separate program in an NMB image that `nmbd` starts or talks to; **SHIP (BASE)** = part of the
image's base system (init, libraries, boot); **SHIP (DATA)** = a file in the image that the kernel or a device
loads (firmware, NVRAM, regulatory data), never executed by `nmbd`. "Notice" = copyright line and licence text in
the image's licences folder and on the about page of 6B.3A. "Source offer" = for GPL/LGPL programs in an image,
the complete corresponding source of exactly the shipped version, including NMB's changes and the scripts that
build and install it, shipped with the image or offered in writing (GPL-2.0 section 3b: valid 3 years; GPL-3.0
section 6).
