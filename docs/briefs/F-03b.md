## 2. Rules applied

- **Confirmed** means: the cited lines at `ad3758c` show the behaviour the brief describes. Where a brief cited a line
  that holds something else, the right line was found and cited instead (for example F-04b item 6: the schema version
  is `nmb/db/schema.sql@ad3758c:5`, not `database.py:5`).
- **Duplicate** of an existing entry: the existing entry already describes the fault (or its correct behaviour already
  covers the case). Only its *Source* is extended; its meaning, packages and status are not changed. A proposal that
  shows the fault still present at `ad3758c` in an entry whose *Status, Python* is `fixed` is not a duplicate: it
  becomes a new entry (*Status, Python* `open`) that names the fixed entry, and the fixed entry stays as it was
  (review of this package, section 6). In the first round, proposals that asked to change an existing entry's text,
  packages or status were listed as rejected with that reason; since the second review (section 7) an existing entry
  is widened where a proposal needs more than a source, and each change is listed in section 7.
- **One entry for several proposals**: proposals of one fault, or of closely tied faults with the same prover, found in
  one or several briefs, are one new entry; the table says "one entry with" the first of them.
- **Rejected**: not a fault of the Python version (a design requirement of the native build, a question, a roadmap
  correction, review findings of a brief), or not a proposal at all.
- **Security and privacy.** Open holes are recorded by category only, as the register's header says. No personal or site data: ISP, router brands, public test hosts and services are written generically.
- **Fields**: *Correct behaviour* from the proposing brief, cited as "brief <package> section <n>", with the roadmap
  rules the brief names; *Package that proves it* as the brief names it; *Python fix commit* `not recorded in the
  source; note: not fixed`; *Status, Go* `open`; *Status, C* `not started`; *Status, Python* `open` (F-06's entry:
  `open; note: documentation only`), as the source at `ad3758c` shows.
